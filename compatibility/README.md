# Using another board

You can follow Lesson 3 with no hardware. To reproduce it, many Arduino-compatible boards can run the same simple serial sketch.

What may change on another board:

- the board package installed in Boards Manager;
- the board name and port selected in Arduino IDE;
- the USB connector and required cable;
- reset or boot behavior during upload;
- pin names and voltage limits in later lessons.

For help adapting a lesson, leave a comment with:

1. your exact board model;
2. your operating system;
3. your Arduino IDE version;
4. the complete error message or the step where the behavior differs.

Do not copy Nano ESP32 wiring into another board without checking that board's pinout and voltage limits.
