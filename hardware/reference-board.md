# Reference board

The course reference board is the **Arduino Nano ESP32 with headers**, product code **ABX00083**.

It provides a current ESP32-S3 platform in the compact Nano form factor, a USB-C connector, and direct support in Arduino IDE. The headers make it convenient to use with a breadboard in later lessons.

The course uses Arduino pin numbering, which is the board default. Prefer symbolic labels such as `D2` in later examples when that makes a sketch easier to adapt between Nano ESP32 pin-numbering modes.

Official references:

- [Arduino Nano ESP32 documentation](https://docs.arduino.cc/hardware/nano-esp32)
- [Nano ESP32 pin-numbering guide](https://support.arduino.cc/hc/en-us/articles/10483225565980-Select-pin-numbering-for-Nano-ESP32-in-Arduino-IDE)
